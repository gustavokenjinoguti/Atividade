# Sistema de Notas do Aluno 🎓

Um script simples em Python para calcular a média de duas notas e determinar o status de aprovação de um aluno.

## 📋 Funcionalidades

* Recebe duas notas decimais através da entrada do usuário.
* Calcula a média aritmética simples.
* Exibe a média final formatada com duas casas decimais.
* Informa o status final do aluno:
  * **APROVADO!** (Média ≥ 7.0)
  * **REPROVADO.** (Média < 7.0)

## 🚀 Como executar

### Pré-requisitos
* Ter o [Python](https://www.python.org/downloads/) instalado na sua máquina (versão 3.x).

### Passo a passo
1. Crie um arquivo chamado `notas.py` e cole o código nele.
2. Abra o terminal ou prompt de comando.
3. Navegue até o diretório onde você salvou o arquivo.
4. Execute o script com o comando:

```bash
python notas.py
